## 🚧 Projects

🔹 See For Me (iOS)

An accessibility-first iOS app designed to help visually impaired users better understand and interact with their surroundings.

The app uses on-device AI to detect real-world objects through the camera and provides audio and haptic guidance to assist users in real time.

🧪 Currently available on TestFlight
👉 https://testflight.apple.com/join/k4ybXBK5

Key features
	•	Real-time object detection (CoreML + Vision)
	•	Voice guidance & accessibility-focused UX
	•	Haptic feedback for spatial awareness
	•	Built with SwiftUI and Swift Concurrency
